# BrideMatch 💍

## Sobre o Projeto

**BrideMatch** é uma plataforma web criada para conectar noivas aos fornecedores ideais para o seu casamento.

O sistema funciona como um serviço de *match*: a noiva preenche seu perfil com informações sobre o estilo do casamento que deseja, preferências, orçamento e outras características relevantes. Os fornecedores, por sua vez, cadastram informações detalhadas sobre seus serviços, portfólio, especialidades e diferenciais.

Com base nessas informações, o **BrideMatch** cruza os dados e sugere os melhores fornecedores para cada noiva, tornando o planejamento do casamento mais prático, personalizado e eficiente.

## Funcionalidades Previstas

- **Cadastro de Noivas** — Criação de perfil com preferências, estilo e orçamento do casamento.
- **Cadastro de Fornecedores** — Registro de serviços, portfólio e informações de contato.
- **Sistema de Match** — Algoritmo que combina perfis de noivas com fornecedores compatíveis.
- **Visualização de Perfis** — Noivas podem explorar os perfis dos fornecedores sugeridos.
- **Conexão Direta** — Facilita o contato entre noivas e fornecedores que fizeram match.

## Objetivo

Simplificar e personalizar o processo de escolha de fornecedores para casamentos, unindo noivas e profissionais do setor de eventos de forma inteligente e eficaz.
